# Project

React + TypeScript + Vite project với Tailwind CSS và shadcn/ui components.

## Yêu cầu

- Node.js (phiên bản 18 trở lên)
- npm hoặc yarn

## Cài đặt

1. Cài đặt dependencies:
```bash
npm install
```

## Chạy project

Để chạy project ở chế độ development:

```bash
npm run dev
```

Project sẽ chạy tại `http://localhost:5173`

## Build

Để build project cho production:

```bash
npm run build
```

## Preview

Để preview build production:

```bash
npm run preview
```
